### ansible-doc
- **copy:** content = tiedoston sisältö, dest = minne tiedosto kirjoitetaan, src = kopioitava lähdetiedosto, owner/group = omistaja ja ryhmä, mode = oikeudet
- **apt:** name = paketin nimi, state = present/absent, update_cache = päivitä pakettilista ensin
- **file:** path = tiedosto tai kansio, state = esim. directory/absent/link, recurse = koske myös alikansioihin
- **user:** name, groups = ryhmät, shell = komentotulkki, create_home = tee kotikansio, comment = kuvaus, system = järjestelmäkäyttäjä
- **authorized_key:** user = kenelle, key = julkinen avain

## a) Sudoless

Tein salasanattoman sudon käsin omalle käyttäjälleni mikael Karvisen ohjeen mukaan (Karvinen 2026a).

```
sudo groupadd sudoless
sudo adduser mikael sudoless
sudo visudo /etc/sudoers.d/sudoless
```
Tiedostoon kirjoitin rivin:
```
%sudoless ALL = (ALL) NOPASSWD: ALL
```
visudo kirjoitti ensin .tmp-tiedostoon, koska se haluaa varmistaa ettei tiedostossa ole virheitä ennen kuin tallentaa sen oikeaan paikkaan.

Testi:
```
ssh localhost
groups
sudo -k
sudo echo "toimii ilman salasanaa"
```
groups-tulosteessa näkyi sudoless ja sudo echo toimi ilman salasanaa. Testasin SSH:n kautta, koska uusi ryhmä tulee voimaan vasta uudella kirjautumisella.

## b) Antero

Tein Ansible-roolin Karvisen mallin mukaan (Karvinen 2026b).

```
$ cat roles/antero/tasks/main.yml
- group:
    name: "sudoless"
    state: present
- user:
    name: "antero"
    state: present
    shell: "/bin/bash"
    groups: ["sudoless"]
- authorized_key:
    user: "antero"
    key: "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIK8oIpGKQjAotSvP5Wd1ggFNjV5JOMhjTvwcY2PKkChp mikael@mikael-virtualbox"
- copy:
    dest: "/etc/sudoers.d/sudoless"
    content: "%sudoless ALL = (ALL) NOPASSWD: ALL\n"
    owner: "root"
    group: "root"
    mode: "0440"
```
Rooli luo sudoless-ryhmän ja käyttäjän antero, lisää anterolle mun julkisen SSH-avaimen ja kirjoittaa sudo-säännön.

![b-ajo](kuva)

Testi:
```
ssh antero@localhost
whoami
groups
sudo -k
sudo echo "antero toimii ilman salasanaa"
```
Kirjautuminen anterona ei kysynyt salasanaa, whoami näytti antero ja sudo toimi ilman salasanaa.

![b-testi](kuva)

Toinen ajo antoi changed=0, eli rooli on idempotentti.

## c) Package

```
$ cat roles/pkgs/tasks/main.yml
- apt:
    name: ["tree", "htop"]
    state: present
    update_cache: true
```

### Ongelma: apt ei päivittynyt
Ensimmäinen ajo epäonnistui:
```
fatal: [localhost]: FAILED! => {"changed": false, "msg": "Failed to update apt cache after 5 retries: "}
```
Ansiblen virheilmoitus ei kertonut syytä, joten ajoin sudo apt-get update käsin. Siitä tuli virhe "Not live until 2026-11-02", eli allekirjoitukset olivat koneen mielestä tulevaisuudesta. date näytti viime keskiviikkoa (28.10.2026), eli virtuaalikoneen kello oli jäljessä.

Korjaus:
```
sudo timedatectl set-ntp true
# Failed to set ntp: NTP not supported
sudo date -s "2026-11-02 15:21"
sudo apt-get update
sudo apt-get -y install systemd-timesyncd
timedatectl
```
timedatectl set-ntp true ei toiminut, koska koneesta puuttui systemd-timesyncd-paketti. Sitä ei voinut asentaa, koska apt ei toiminut väärän kellon takia, joten asetin kellon ensin käsin ja asensin paketin sen jälkeen.

![kello](kuva)

Uusi ajo onnistui:
```
which tree htop
/usr/bin/tree
/usr/bin/htop
```

## d) File

```
$ cat roles/tiedosto/tasks/main.yml
- copy:
    dest: "/home/mikael/muistio.txt"
    content: |
      Tämä tiedosto on tehty Ansiblella.
      Omistaja on mikael ja ryhmä mikael.
      Oikeudet ovat 0640.
    owner: "mikael"
    group: "mikael"
    mode: "0640"
```
```
$ ls -l ~/muistio.txt
-rw-r----- 1 mikael mikael 94  2.11. 15:25 /home/mikael/muistio.txt
```
0640 on symbolisena -rw-r-----. Omistaja mikael saa lukea ja kirjoittaa (4+2=6), ryhmä mikael saa vain lukea (4) ja muut eivät saa tehdä mitään (0).

## e) Jotain muuta: lineinfile

```
$ cat roles/motd/tasks/main.yml
- lineinfile:
    path: "/etc/motd"
    line: "Tervetuloa! Tämä kone on Ansiblen hallinnassa."
```
lineinfile lisää yhden rivin olemassa olevaan tiedostoon, jos sitä ei siellä vielä ole. Muu sisältö säilyy, kun taas copy korvaisi koko tiedoston. Rivi näkyi kirjautuessa ssh localhost -komennolla.
