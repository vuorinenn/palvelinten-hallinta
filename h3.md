## a) Apassi

Apache oli jo asennettuna h0:n jäljiltä, mutta se ei ollut käynnissä:
```
sudo systemctl status apache2 --no-pager
# Active: inactive (dead), disabled
```

### Ongelma: Apache ei käynnistynyt
```
sudo systemctl enable --now apache2
# Job for apache2.service failed because the control process exited with error code.
```
Vianetsintä:
```
sudo journalctl -xeu apache2.service --no-pager | tail -20
sudo apache2ctl configtest
# Syntax OK
sudo ss -tlnp | grep ':80'
# LISTEN 0 4096 *:80 *:* users:(("caddy",pid=942,fd=6))
```
[selitä: configtest näytti asetusten olevan kunnossa, ss paljasti että Caddy kuunteli porttia 80. Kaksi demonia ei voi kuunnella samaa porttia]

Korjaus:
```
sudo systemctl disable --now caddy
sudo systemctl enable --now apache2
```
![apache-käynnissä](kuva)

### Kotisivu tavallisen käyttäjän kansioon
```
mkdir ~/publicsite
echo "Mikaelin kotisivu, tehty ilman sudoa" > ~/publicsite/index.html
chmod ugo+x /home/mikael/
chmod ugo+x /home/mikael/publicsite/
chmod ugo+r /home/mikael/publicsite/index.html
```
[selitä miksi chmod tarvitaan: Apache toimii käyttäjänä www-data, joka tarvitsee x-oikeuden kansioihin ja r-oikeuden tiedostoon (Karvinen 2026c)]

### Virtuaalipalvelin
```
$ cat /etc/apache2/sites-available/mikael.conf
<VirtualHost *:80>
        ServerName mikael.example
        DocumentRoot /home/mikael/publicsite/

        <Directory /home/mikael/publicsite/>
                require all granted
        </Directory>
</VirtualHost>
```
```
sudo a2ensite mikael.conf
sudo a2dissite 000-default.conf
sudo apache2ctl configtest
sudo systemctl restart apache2
```
[selitä mitä a2ensite ja a2dissite tekevät]

### Testi
```
curl localhost
echo "Muokattu tavallisena käyttäjänä ilman sudoa" >> ~/publicsite/index.html
curl localhost
curl mikael.example
```
[mitä tapahtui: muokkaus näkyi heti ilman sudoa]

## b) Moottorix

Sammutin Apachen ja asensin Nginxin:
```
sudo systemctl disable --now apache2
sudo apt-get -y install nginx
curl localhost
```

### Huomio: Nginx näytti Apachen sivua
[selitä: curl näytti Apachen oletussivun HTML:n, vaikka Apache oli sammutettu]
```
curl -sI localhost | grep -i server
# Server: nginx
sudo ss -tlnp | grep ':80'
systemctl is-active apache2 nginx
# inactive
# active
```
[selitä syy: Nginxin oletusasetus käyttää samaa kansiota /var/www/html/, jossa oli Apachen index.html]
![nginx-server](kuva)

### Nginxin asetus
```
$ cat /etc/nginx/sites-available/mikael
server {
        listen 80 default_server;
        listen [::]:80 default_server;
        server_name mikael.example;
        root /home/mikael/publicsite;
        index index.html;
}
```
```
sudo rm /etc/nginx/sites-enabled/default
sudo ln -s /etc/nginx/sites-available/mikael /etc/nginx/sites-enabled/mikael
sudo nginx -t
sudo systemctl restart nginx
```
[selitä: rm poistaa vain oletussivun linkin, ln -s ottaa oman sivun käyttöön, nginx -t tarkistaa asetukset]

### Testi
```
echo "Nyt palvelimena toimii Nginx" >> ~/publicsite/index.html
curl -s localhost
curl -sI localhost | grep -i server
```
[mitä tapahtui]
